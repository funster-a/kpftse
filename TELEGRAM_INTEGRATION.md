## 📋 Следующие шаги для запуска

1. **Создайте Telegram бота:**
   - Откройте @BotFather в Telegram
   - Отправьте `/newbot`
   - Сохраните токен

2. **Получите Chat ID:**
   - Используйте @userinfobot для получения вашего Chat ID
   - Или создайте группу и добавьте бота

3. **Настройте Backend:**
   ```bash
   cd backend
   npm install
   cp env.example .env
   # Отредактируйте .env и добавьте токен и chat_id
   npm start
   ```

4. **Настройте Frontend (опционально):**
   ```bash
   cd frontend
   # Создайте .env если нужно изменить URL API
   # VITE_API_URL=http://localhost:3000
   npm run dev
   ```

## 🔧 Технические детали

### Структура проекта
```
backend/
  ├── server.js          # Express сервер
  ├── telegram.js        # Логика отправки в Telegram
  ├── package.json
  ├── env.example        # Пример конфигурации
  └── README.md

frontend/
  └── src/
      ├── components/
      │   ├── Catalog/   # Обновлена форма заявки
      │   └── Contact/   # Обновлена форма контактов
      └── config/
          └── api.ts     # Конфигурация API
```

### Переменные окружения

**Backend (.env):**
- `TELEGRAM_BOT_TOKEN` - токен бота от @BotFather
- `TELEGRAM_CHAT_ID` - ID чата менеджера
- `PORT` - порт сервера (по умолчанию 3000)

**Frontend (.env):**
- `VITE_API_URL` - URL backend сервера (по умолчанию http://localhost:3000)

## 🚀 Развертывание

### Локальная разработка
1. Запустите backend: `cd backend && npm start`
2. Запустите frontend: `cd frontend && npm run dev`
3. Тестируйте отправку заявок

### Продакшн
- Backend можно развернуть на VPS с PM2
- Frontend можно развернуть на Vercel/Netlify
- Не забудьте настроить CORS для вашего домена
