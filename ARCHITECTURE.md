# Архитектура системы отправки заявок через Telegram

## Варианты реализации

### Вариант 1: Node.js Backend (Рекомендуемый) ⭐
**Преимущества:**
- Простая интеграция с React фронтендом
- Легко развернуть на VPS/хостинге
- Можно использовать Express.js
- Хорошая документация

**Структура:**
```
backend/
  ├── server.js          # Express сервер
  ├── telegram.js        # Логика отправки в Telegram
  ├── routes/
  │   └── orders.js      # API endpoint для заявок
  ├── config.js          # Конфигурация (токены, chat_id)
  └── package.json
```

### Вариант 2: Serverless Functions (Vercel/Netlify)
**Преимущества:**
- Бесплатный хостинг
- Автоматическое масштабирование
- Не нужно управлять сервером

**Недостатки:**
- Ограничения по времени выполнения
- Может быть медленнее

### Вариант 3: Python Backend (Flask/FastAPI)
**Преимущества:**
- Простой синтаксис
- Хорошие библиотеки для Telegram

## Рекомендуемая архитектура (Вариант 1)

### Поток данных:
```
Frontend (React) 
  ↓ POST /api/orders
Backend API (Node.js/Express)
  ↓ Отправка сообщения
Telegram Bot API
  ↓ Уведомление
Менеджер (Telegram)
```

### Что нужно:
1. **Telegram Bot Token** - получить у @BotFather
2. **Chat ID менеджера** - ID чата куда отправлять заявки
3. **Backend сервер** - Node.js приложение

### Формат сообщения в Telegram:
```
🆕 Новая заявка

👤 Клиент: Иван Иванов
📞 Телефон: +7 (777) 123-45-67
📧 Email: ivan@example.com
🏢 Компания: ООО "Пример"

📦 Товары:
1. Электродвигатель АИР 80А2 - Цена по запросу
2. Частотный преобразователь ESQ900 - Цена по запросу

💬 Комментарий: Нужна срочная доставка

⏰ Дата: 2025-01-XX XX:XX
```
