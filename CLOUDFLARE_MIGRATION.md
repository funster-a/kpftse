# Миграция на Cloudflare Workers

## Почему Cloudflare Workers?

- ✅ **Бесплатный хостинг** - 100,000 запросов в день бесплатно
- ✅ **Глобальная сеть** - ваши запросы обрабатываются ближайшим дата-центром
- ✅ **Автоматическое масштабирование** - не нужно думать о нагрузке
- ✅ **Интеграция с Pages** - легко работать с фронтендом на Cloudflare Pages
- ✅ **Быстрый деплой** - изменения применяются за секунды

## Шаги миграции

### 1. Установка Wrangler

```bash
npm install -g wrangler
wrangler login
```

### 2. Настройка проекта

```bash
cd workers
npm install
```

### 3. Локальная разработка

Создайте `.dev.vars`:
```env
TELEGRAM_BOT_TOKEN=ваш_токен
TELEGRAM_CHAT_ID=ваш_chat_id
```

Запустите:
```bash
npm run dev
```

### 4. Деплой

```bash
# Установите секреты
wrangler secret put TELEGRAM_BOT_TOKEN
wrangler secret put TELEGRAM_CHAT_ID

# Деплой
npm run deploy
```

### 5. Обновление Frontend

Обновите URL API в `frontend/.env`:
```env
VITE_API_URL=https://kpftse-telegram-api.your-subdomain.workers.dev
```

Или обновите напрямую в коде компонентов.

## Сравнение с Node.js backend

| Параметр | Node.js | Cloudflare Workers |
|----------|---------|-------------------|
| Хостинг | Нужен VPS/сервер | Бесплатно |
| Настройка | Сложнее | Проще |
| Масштабирование | Вручную | Автоматически |
| Скорость деплоя | Минуты | Секунды |
| Глобальная сеть | Нет | Да |
| Лимиты | Зависит от сервера | 100k/день бесплатно |

## Что изменилось в коде?

- Используется стандартный Fetch API вместо Node.js модулей
- Переменные окружения через `env` объект
- CORS настроен вручную
- Логика отправки в Telegram через fetch вместо библиотеки

## Преимущества для вашего проекта

1. **Экономия** - не нужно платить за VPS
2. **Надежность** - Cloudflare гарантирует 99.9% uptime
3. **Скорость** - запросы обрабатываются ближайшим дата-центром
4. **Простота** - один команда для деплоя
