# Backend API для отправки заявок в Telegram

## Настройка

### 1. Создание Telegram бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите токен бота
4. Сохраните токен

### 2. Получение Chat ID

Есть несколько способов:

**Способ 1: Через бота**
1. Найдите [@userinfobot](https://t.me/userinfobot) или [@getidsbot](https://t.me/getidsbot)
2. Начните диалог с ботом
3. Бот покажет ваш Chat ID

**Способ 2: Через группу**
1. Создайте группу в Telegram
2. Добавьте вашего бота в группу как администратора
3. Отправьте любое сообщение в группу
4. Откройте: `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates`
5. Найдите `"chat":{"id":-123456789}` - это ID группы

### 3. Установка зависимостей

```bash
cd backend
npm install
```

### 4. Настройка переменных окружения

1. Скопируйте `.env.example` в `.env`:
```bash
cp .env.example .env
```

2. Откройте `.env` и заполните:
```
TELEGRAM_BOT_TOKEN=ваш_токен_бота
TELEGRAM_CHAT_ID=ваш_chat_id
PORT=3000
```

### 5. Запуск сервера

**Режим разработки:**
```bash
npm run dev
```

**Продакшн:**
```bash
npm start
```

Сервер запустится на `http://localhost:3000`

## API Endpoints

### POST /api/orders
Отправка заявки с товарами из каталога

**Тело запроса:**
```json
{
  "name": "Иван Иванов",
  "phone": "+7 (777) 123-45-67",
  "email": "ivan@example.com",
  "company": "ООО Пример",
  "comment": "Нужна срочная доставка",
  "products": [
    {
      "id": 1,
      "name": "Электродвигатель АИР 80А2",
      "price": "Цена по запросу"
    }
  ]
}
```

### POST /api/contact
Отправка простой заявки из формы контактов

**Тело запроса:**
```json
{
  "phone": "+7 (777) 123-45-67",
  "message": "Хочу получить консультацию"
}
```

## Проверка конфигурации

### Проверка Chat ID

Запустите утилиту для проверки вашего Chat ID:

```bash
npm run check-chat
```

Эта утилита:
- Проверит правильность Chat ID
- Покажет информацию о чате
- Отправит тестовое сообщение
- Покажет все доступные чаты, если Chat ID не установлен

### Получение Chat ID через API

Если у вас нет Chat ID, вы можете получить его:

1. **Для личного чата:**
   - Начните диалог с вашим ботом
   - Отправьте любое сообщение
   - Запустите: `npm run check-chat`

2. **Для группы:**
   - Добавьте бота в группу как администратора
   - Отправьте сообщение в группу
   - Запустите: `npm run check-chat`

3. **Через браузер:**
   - Откройте: `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates`
   - Найдите `"chat":{"id":123456789}` в ответе

## Развертывание

### На VPS (Ubuntu/Debian)

1. Установите Node.js:
```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs
```

2. Клонируйте проект и установите зависимости
3. Настройте `.env`
4. Используйте PM2 для запуска:
```bash
npm install -g pm2
pm2 start server.js --name kpftse-backend
pm2 save
pm2 startup
```

### На Heroku

1. Создайте приложение на Heroku
2. Установите переменные окружения в настройках
3. Деплойте код

## Безопасность

- Никогда не коммитьте `.env` файл в Git
- Используйте разные токены для разработки и продакшна
