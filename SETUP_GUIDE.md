# Руководство по настройке системы отправки заявок

## Быстрый старт

### Шаг 1: Создание Telegram бота

1. Откройте Telegram
2. Найдите [@BotFather](https://t.me/BotFather)
3. Отправьте команду `/newbot`
4. Следуйте инструкциям:
   - Введите имя бота (например: "Техснабэлектрикс Заявки")
   - Введите username бота (должен заканчиваться на `bot`, например: `kpftse_orders_bot`)
5. Сохраните полученный токен (выглядит как: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

### Шаг 2: Получение Chat ID

**Вариант А: Личный чат с менеджером**

1. Найдите [@userinfobot](https://t.me/userinfobot) в Telegram
2. Начните диалог с ботом
3. Бот покажет ваш Chat ID (число, например: `123456789`)
4. Сохраните этот ID

**Вариант Б: Группа для заявок**

1. Создайте группу в Telegram
2. Добавьте вашего бота в группу как администратора
3. Отправьте любое сообщение в группу
4. Откройте в браузере: `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
5. Найдите в ответе `"chat":{"id":-123456789}` - это ID группы (отрицательное число)

### Шаг 3: Настройка Backend

1. Перейдите в папку `backend`:
```bash
cd backend
```

2. Установите зависимости:
```bash
npm install
```

3. Создайте файл `.env`:
```bash
cp env.example .env
```

4. Откройте `.env` и заполните:
```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
TELEGRAM_CHAT_ID=ваш_chat_id
PORT=3000
```

5. Запустите сервер:
```bash
npm start
```

Сервер должен запуститься на `http://localhost:3000`

### Шаг 4: Настройка Frontend

1. Перейдите в папку `frontend`

2. Создайте файл `.env` (если нужно изменить URL API):
```env
VITE_API_URL=http://localhost:3000
```

3. Запустите фронтенд:
```bash
npm run dev
```

### Шаг 5: Тестирование

1. Откройте сайт в браузере
2. Заполните форму заявки (в каталоге или на главной странице)
3. Отправьте заявку
4. Проверьте Telegram - должно прийти сообщение с данными заявки

## Развертывание на продакшн

### Backend на VPS

1. Подключитесь к серверу по SSH
2. Установите Node.js:
```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs
```

3. Клонируйте проект на сервер
4. Установите зависимости и настройте `.env`
5. Установите PM2:
```bash
npm install -g pm2
```

6. Запустите сервер:
```bash
pm2 start server.js --name kpftse-backend
pm2 save
pm2 startup
```

7. Настройте Nginx как reverse proxy (опционально)

### Frontend на Vercel/Netlify

1. Создайте аккаунт на Vercel или Netlify
2. Подключите репозиторий
3. Установите переменную окружения:
   - `VITE_API_URL` = URL вашего backend сервера
4. Деплойте проект

## Проверка работы

### Тест API напрямую

```bash
curl -X POST http://localhost:3000/api/orders \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Тестовый клиент",
    "phone": "+7 (777) 123-45-67",
    "email": "test@example.com",
    "company": "Тестовая компания",
    "comment": "Тестовая заявка",
    "products": [
      {
        "id": 1,
        "name": "Тестовый товар",
        "price": "1000 руб"
      }
    ]
  }'
```

Если все настроено правильно, вы получите сообщение в Telegram.

## Устранение неполадок

### Бот не отправляет сообщения

1. Проверьте, что токен правильный
2. Проверьте, что Chat ID правильный
3. Убедитесь, что бот добавлен в группу (если используете группу)
4. Проверьте логи сервера

### CORS ошибки

Убедитесь, что в `backend/server.js` настроен CORS правильно:
```javascript
app.use(cors({
  origin: 'http://localhost:5173' // или ваш домен
}));
```

### Порт занят

Измените PORT в `.env` файле на другой порт (например, 3001)

## Безопасность

⚠️ **Важно:**
- Никогда не коммитьте `.env` файлы в Git
- Используйте HTTPS в продакшне
- Ограничьте доступ к API (можно добавить rate limiting)
- Регулярно обновляйте зависимости
